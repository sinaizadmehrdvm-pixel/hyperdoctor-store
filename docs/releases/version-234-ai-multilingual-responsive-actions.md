# Version 234 — Multilingual & Responsive AI Actions

Date: 2026-09-06

## Scope

Adds production AI shortcuts for the most common editor tasks while preserving factual integrity and explicit human approval.

## Implemented

- Four-language translation action for Persian, Turkish, English and Arabic.
- Translation preserves brand/product names, links, images and factual meaning.
- Responsive optimization action for desktop, tablet and mobile.
- Responsive mode focuses on widths, spacing, heights, card columns, alignment and visibility settings.
- Content-polish action for a more premium, concise and trustworthy medical-equipment presentation.
- Page-structure action for hierarchy, CTA placement and visual rhythm without fabricating business facts.
- All quick actions work on the whole page or the currently selected section.
- Section scope remains enforced again on the server even if the model returns unrelated changes.
- Suggestions are preview-only until accepted and are never automatically published.

No synthetic product, price, certification, regulatory or clinical data is introduced by these workflows.
